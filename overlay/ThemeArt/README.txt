THEME ART — per-theme overlay images
=====================================

Drop one image per theme in this folder. When that theme is active, the image
shows on your OBS overlay (enable "Theme Art" in the overlay editor and drag it
where you want). Images placed here are BUILT INTO the app (they ship with the
installer). A streamer can override any of them at runtime by dropping a file of
the same name into:  %AppData%\Tequilas Tavern\ThemeArt\

FILE NAMES  (use the exact name; .png recommended — transparent PNG looks best)
------------------------------------------------------------------------------
  kingdom-hearts.png
  legend-of-zelda.png
  mario.png
  dark.png
  light.png
  warrior-of-light.png
  reptile.png
  amber.png
  ocean.png
  royal.png
  crimson.png
  mono.png

Accepted extensions: .png .jpg .jpeg .gif .webp
(If you add a new theme later, the file name is the theme name in lowercase with
spaces/symbols turned into single dashes, e.g. "Final Fantasy VII" -> final-fantasy-vii.png)

TIP: the overlay is 1280x720. A character image around 300-500 px tall, with a
transparent background, sits nicely in a corner.
